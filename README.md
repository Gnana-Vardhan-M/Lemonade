# 🍋 Lemonade

A simple Android app demonstrating button functionality in Kotlin. This project was created as part of the **Google Kotlin Course** to explore UI interactions and state management.

---

## 📌 Features
- Interactive button-based UI.
- Step-by-step lemonade-making process.
- Simple state management using `ViewModel`.
- Clean and beginner-friendly Kotlin code.

---

## 🛠️ Setup & Installation

### Prerequisites
- Android Studio (latest version recommended)
- Kotlin support enabled
- Android device or emulator running **Android 5.0+**

### Steps
1. **Clone the repository**:
   ```sh
   git clone https://github.com/Gnana-Vardhan-M/Lemonade.git
   cd Lemonade
   ```
2. **Open the project** in **Android Studio**.
3. **Build & run** the project on an emulator or real device.

---

## 🎮 How to Play?
1. Tap the **lemon** to squeeze it.
2. Keep tapping until the juice is ready.
3. Tap the **glass** to drink lemonade.
4. Start over and enjoy! 🍹
